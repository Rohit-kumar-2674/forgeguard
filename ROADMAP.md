# Roadmap

## 0.1 — Foundation

- Local CLI, modular checks, JSON output, tests, CI, and community documentation.

## 0.2 — Interoperability

- SARIF output, configuration schema, exclusions, fingerprints, and documented JSON compatibility.

## 0.3 — Dependency intelligence

- Parse npm and Python dependency graphs and query an authoritative vulnerability service with explicit caching and offline behavior.

## 0.4 — Supply chain

- CycloneDX/SPDX SBOM generation and stronger GitHub Actions analysis.

## 0.5 — GitHub integration

- A least-privilege GitHub Action with job summaries and opt-in PR reporting.

## Later, after proven demand

- Plugin API, historical dashboard, hosted API, additional ecosystems, signed releases, and package registries.

Adoption, contributor count, downloads, and OpenSSF criticality are outcomes—not metrics ForgeGuard will manipulate.
